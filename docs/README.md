## Orden de lectura sugerido

- **Usuario final:** manual de usuario (o los manuales por rol en Figma) y datos de prueba.
- **Desarrollo:** README (arquitectura), desarrollo y sistema de diseño.
- **Informe del TCC:** README (descripción, marco teórico, mapa de pantallas, capturas) y la auditoría.

## Mantener la documentación al día

Una pantalla nueva o un cambio de flujo actualiza en el mismo commit el mapa de pantallas del README, el manual de
usuario y el CHANGELOG; si cambia el aspecto, también las capturas.
